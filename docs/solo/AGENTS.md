# Solo：Codex 仓库工作规则

先读 README.md、docs/00_总则与决策.md、docs/03_密码学与交易协议.md、docs/06_发行手续费与会计.md、docs/15_Codex执行手册.md，再按任务依赖读其余文档。本包是全量规格，不是已完成软件。

## 不可改变的范围

独立单币PoS链；私密支付；独立公钥原生持仓；无通用智能合约/其他可流通币/跨链/DEX/托管；无实名/手机号/邮箱/生物识别；本地密码及恢复；家庭节点与完整钱包/节点/浏览器；无MVP删减。

## 安全规则

不自己发明曲线、签名和证明系统；不关闭验证；不把JSON余额表当链；不让服务器持有种子或完整查看密钥；不把广播成功当结算；金额不使用浮点；不得把上线外部材料伪造为已取得。

共享 Rust 核心是签名/金额/状态规则唯一实现。上游密码学严格锁定源码、电路与参数；新增原生动作必须加入binding、权限和供给不变量测试。任何规则变化先写ADR并同步合同、文档和测试。

## 执行

按 codex/tasks.json 的依赖推进全量任务，无需每个模块询问是否继续。实现真实代码与真实测试；只在必要的真实外部输入缺失时记录阻断，继续完成不依赖它的功能。

每个任务更新 codex/implementation_status.json，附实际文件和测试证据。未经执行的测试不可标通过。上下文不足时更新 codex/NEXT.md，不谎称完成。

## 质量命令

必须实现 docs/15 中全部 just 命令。fmt/lint/unit/crypto/protocol/integration/钱包与节点E2E/隐私/故障/性能/发布检查均保留。UI mock 只可做布局，不算资金功能通过。

## 权限与数据

主网密钥只能由真实参与者产生，不能提交Git。发布密钥与资金/共识键隔离。只读网关无资金管理权限。主网缺少审计/创世签名/真实网络材料则preflight失败，不能用一个boolean绕过。

## 最终报告

列真实实现、实际运行命令、结果、未执行项目与具体阻断。文档包自带reference程序只验证整数模型，不得称整条链或密码学已测试。

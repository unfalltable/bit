# 07　钱包内核、安全恢复与网络隐私

## 7.1 密钥与 vault

随机数来自操作系统 CSPRNG，不用时间戳、钱包密码、手机号或 Math.random 生成种子。采用上游兼容的高熵恢复词编码，固定种子转换规则并提供向量；默认不额外增加容易遗忘的隐藏助记词 passphrase。

wallet root 派生支付花费/查看密钥、持仓根、收据加密根。不同用途使用不同域，资金密钥绝不派生给在线节点作为共识密钥。支付密钥与各 position secret 不通过日志、分析、剪贴板或后台上传。

Vault 使用随机 256 位 DEK；Argon2id 从用户本地密码和随机 128 位 salt 派生 KEK，用 XChaCha20-Poly1305 包裹 DEK。DEK 再加密 seed 与敏感元数据；数据库键从 DEK 独立派生。AEAD nonce 每次随机，AAD 包含文件版本、网络上下文和 vault UUID。

Argon2id 初始参数 m=64 MiB、t=3、p=4，属于 RFC 9106 对受限环境给出的配置方向；在支持平台评估耗时并只能按版本规则提高，不能不提示就降低到弱短密码保护。[S18]

密码要求至少 10 个字符，推荐长口令；不要求手机号、生物识别或短信。在线错误重试限流只能降低交互攻击，不能当作加密文件离线抗破解的保证。忘记密码可以恢复词新建 vault；忘记全部秘密无法由客服找回。

## 7.2 内存与操作系统

Rust 敏感对象使用可清零容器，尽量限制复制与存活时间；禁止在 panic、Debug、telemetry 中输出密钥。FFI 不把长久种子作为普通 Dart String 返回；备份显示使用短生命周期、明确授权的敏感会话，但不得宣传 UI 内存能够完全避免截屏/进程入侵。

不使用 `local_auth` 等生物识别授权流程，不把系统硬件钥匙设置为必须指纹/面容才可使用。可利用系统提供的非生物识别安全存储来保护辅助随机材料，但恢复不能只依赖某一设备。

锁屏/切后台自动遮盖敏感界面，默认后台超过 30 秒锁定、前台无操作 120 秒锁定。导出恢复词、改密码、签署 validator 变更、单笔超过本地大额阈值时重新要求本地密码。小额已解锁会话仍逐笔显示确认按钮，绝不默认自动支付。

Android 阻止普通系统截图的能力应启用；iOS 采取截屏检测、后台快照遮挡并说明不能完全阻止拍照。不得承诺所有平台均无法截图。

## 7.3 钱包数据库

SQLCipher 存储 notes、nullifiers、positions、本地交易计划、同步游标、contacts、invoices 与轻客户端可信状态。只存必要的私钥引用，种子位于独立 vault。

在同一个数据库事务中更新一批扫描数据、票据状态、position 事件与扫描高度。中断后可重扫同一区间而不重复入账。恢复必须从可信历史重建状态，而不信任同步服务给的 wallet_id 余额。

数据库备份不代替种子备份；种子备份不恢复从未上链的联系人备注，两类备份在页面上区分。加密备份带版本、校验和与 KDF 参数，导入前先检查大小和格式，不盲目信任用户提供的超大 KDF 参数耗尽内存。

## 7.4 转账计划状态机

```text
DRAFT → VALIDATED → INPUTS_RESERVED → PROVING → READY_TO_SIGN
→ SIGNED → BROADCASTING → PENDING → INCLUDED_UNVERIFIED
→ CONFIRMED
```

旁路状态：USER_CANCELLED、PROOF_FAILED、NETWORK_UNKNOWN、EXPIRED、CONFLICTED、REJECTED。

输入在本地预留防止两个窗口双花；保留 owner/plan_id 和到期高度。解锁预留前必须确认原交易没有待确认或已花费状态。NETWORK_UNKNOWN 不允许直接重建另一笔付款。原交易可逐字节重播；重新报价/重新构造需要新确认。

广播成功后保存完整 envelope 和 tx_id；本地断电恢复后先追踪它。UI 时间进度只表示阶段，不伪造证明或到账百分比。取消证明任务可终止本地计算，但不能取消已经被网络确认的交易。

## 7.5 收款地址与二维码

地址沿用选定上游编码及新的本链 HRP；给每笔收款生成新 diversifier。展示标签仅本地联系人别名，不作为链上身份认证。

`solo:<address>?amount=<decimal>&network=<chain_context_hex>&invoice=<base64url>&expires=<unix_seconds>` 为产品 URI。地址、金额上限、字符集、链上下文和参数长度严格校验；不执行其中的 URL、脚本或任意深链动作。未知必要参数拒绝，未知可选参数只忽略显示，不进入交易授权。

invoice 字段进入加密 memo，不公开；expires 控制支付请求界面，不是所有链上转账的撤销权。扫描网页二维码不得打开摄像头之外的任意系统权限。

## 7.6 Tor 与统一网络出口

所有钱包链查询、广播、参数下载和检查点更新经 Rust NetworkClient；Arti 支持作为嵌入式 Tor 客户端，但移动端生命周期与构建仍需本项目验证。[S19]

默认 privacy_required=true。Tor 建链失败、DNS 失败或网关不可用时显示真实失败与重试，不切换 Flutter HTTP 直连。使用远端名称解析，不先向本地 DNS 查询私密目的地址。对应用中所有 HTTP 客户端做静态审查与抓包测试。

手机 app 更新由平台渠道处理，不宣称因此没有任何平台可见元数据。节点 P2P 网络不使用钱包默认 Tor 策略来保证性能，也不向用户宣传节点 IP 匿名。

## 7.7 同步内容、完整性与隐私

每个 compact block 包含固定高度、交易摘要列表、output payload、nullifier 列表、承诺树增量与公开持仓收据/事件。其规范摘要被写入链状态，客户端用已验证根验证摘要，然后连续重算树。服务器漏掉 output、删掉 receipt 或重排事件会导致摘要/连续性不符。

不得让服务器按用户私钥、完整查看密钥、地址列表筛选数据。历史 memo 可按标准匿名区块批次下载，而不是直接暴露“我关心这个地址”。持仓查询是公开的，但钱包仍优先从通用事件恢复，避免对同一批 position 发查询造成聚类。

轻客户端验证只能证明内容和一致性，不能强迫服务器提供数据；所有端点拒绝服务时显示不可同步，不伪造当前余额。至少三个独立服务配置，连接到两个验证证人，缓存选择不要形成全体用户的唯一单点。

## 7.8 带宽与手机能力的真实边界

完整本地扫描会随全网使用量增长。计算例子：若 compact 平均 1 KB/交易、持续 20 TPS，仅 compact 原始流量约 1.728 GB/日，尚未计算传输开销。这是示例推算，不是本项目已经测得的尺寸。

因此“节点可验证 20 TPS”不自动意味着手机可廉价无限同步。正式容量选择必须同时通过节点 CPU、手机扫描、数据流量与恢复测试。UI 提供同步数据估算、按需暂停和 Wi-Fi 提示；不能悄悄用上传查看密钥换取速度。

完整交付不等于无限容量：mainnet profile 在实测报告中固定区块上限，若钱包日常预算不通过，就降低该 profile 的吞吐上限而不删掉功能。任何降低隐私保证的服务端扫描方案均不属于本版默认实现。

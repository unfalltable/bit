# 10　数据模型、索引与迁移

## 10.1 数据真相的三个层级

链共识状态是资金真相；钱包数据库是用户可解密资产与本地事务缓存；公开索引是可重建的读模型。不能通过修改 PostgreSQL 或管理面板改变链上余额，也不能把索引扫描到的明文记录当作私密余额数据库。

## 10.2 钱包表

`wallet_meta`：vault UUID、版本、chain_context、backup_verified、最后可信/扫描高度。

`notes`：commitment 主键、加密解密结果、value 字符串、asset_id、位置、nullifier、spend_status、created_height、reserved_plan_id。只有已验证本币且非空票据可计入可花费余额。

`plans`：plan_id、kind、effect_hash、状态、原 envelope、tx_id、有效高度、创建时间、脱敏显示摘要；敏感 witness 不持久化或单独短期加密，过期清除。

`positions`：position_id、validator_id、owner key reference、加密 nonce、shares、pending、sequence、状态高度。

`exit_tickets`：ticket_id、position_id、cohort_id、units、到期双条件、领取状态和已验证高度。

`transactions`：tx_id、类型、方向、金额、费用、阶段、高度、发票本地关联、memo、本地标签。

`contacts`、`invoices`、`invoice_payments`、`checkpoints`、`scan_batches`、`schema_migrations`。

表中金额以规范十进制字符串保存或固定 16 字节数值保存；不要使用 SQLite REAL。SQLCipher 是整个数据库文件真实加密，WAL/临时文件也必须符合其安全方式。

## 10.3 公开索引表

`blocks`、`transactions_public`、`validators`、`validator_changes`、`stake_positions_public`、`exit_cohorts`、`exit_tickets_public`、`supply_snapshots`、`evidence_events`、`indexer_cursor`。

公开 transaction 表没有 from_address、to_address、private_amount 列。允许存公开手续费、action type、承诺/nullifier 摘要、position_id 等本来公开的数据。不得从运营者日志补出用户 IP/设备身份表。

`contracts/indexer.sql` 提供初始建表合同。只读服务数据库角色只有 SELECT；索引器有独立写权限；没有对外 SQL 接口。索引器读取新块时先验证上游链/高度，原子写入整块与 cursor，唯一键确保重复扫描无重复行。

## 10.4 Compact 数据与保存

compact records 必须保存足以恢复支付与持仓的密文、树增量和恢复收据；不能只保存明文 UI 摘要。历史数据按 immutable chunk 保存到至少两个独立来源，chunk hash 被验证链状态绑定。

家庭节点可裁剪已经过安全窗口的区块全文和非必要查询索引；仍保留当前状态、nullifier、可信同步所需元数据。公开历史服务保存全部恢复数据，用户可自己运行。任何服务移除历史数据前须有可验证备份与公告，不把历史恢复建立在唯一商业服务器上。

## 10.5 数据迁移

每次数据库升级有递增版本、迁移文件 checksum、测试前后统计。钱包迁移前创建加密备份，先完整校验再原子切换，不在失败时删除旧 vault。任何迁移不改变 seed/key derivation。

链状态迁移仅在已公布协议升级高度执行，输入旧状态根、迁移二进制 hash、输出新状态根及不变量报告必须可重演。多个独立平台对同一快照迁移应得到相同根。

索引 schema 可以独立升级，失败时从最后确认 cursor 重建；浏览器临时不可用不影响链共识与钱包私钥。

## 10.6 幂等/一致性索引

node `FinalizeBlock/Commit`、indexer 每块写入、wallet 每批扫描和发票对账都有独立幂等键。不能用现实时间作为唯一事件 ID；采用 chain_context+height+transaction_index+event_index，或者已规范定义的 tx_id/position_id。

支付入账、持仓生效、退出领取必须以相应高度的状态 proof 通过为准；跨服务数据显示不同高度时附带高度，不静默混成一个“实时余额”。

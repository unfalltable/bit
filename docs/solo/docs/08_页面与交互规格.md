# 08　全量页面、交互与文案规格

## 8.1 全局设计规范

手机底部导航为“钱包、质押、记录、设置”。首页三个主操作为“收款、转账、质押”，不放行情、杠杆、推荐收益榜或广告。中文版与英文版必须完整，无生物识别词条和手机号注册页面。

正常 UI 可清晰留白、深浅主题，颜色不是判断状态的唯一方式；文字缩放 200% 可用，触控目标至少 44 逻辑像素，金额单独一行，长地址可复制和核对首尾。余额隐藏状态默认随锁定保留，不用截断小数掩盖费用。

每个页面都需实现 loading、empty、error、offline、locked 五类适用状态。错误使用 `E_*` 稳定码映射到易理解中文，同时可展开已脱敏技术详情。成功状态必须来自 wallet-core 的验证后事件，不能从前端倒计时触发。

下表的“页面编号”既用于路由、截图基线，也用于 requirements traceability。

## 8.2 钱包引导与安全页面

| ID/路由 | 内容与字段 | 主操作与校验 | 状态与验收 |
|---|---|---|---|
| W01 /welcome | 本地钱包说明、隐私边界、创建/恢复 | 进入创建或恢复，不要求账号 | 断网可进入；无身份 SDK |
| W02 /create/password | 密码、重复密码、非托管说明 | 至少 10 字符；一致后创建 | RNG 失败不得继续；不打印密码 |
| W03 /backup | 恢复词、保存说明 | 本地密码再验证、逐步展示 | 后台立即遮挡；禁止默认复制全部 |
| W04 /backup/verify | 随机位置的恢复词验证 | 验证通过后标记本地已备份 | 错误不销毁钱包；能返回重看 |
| W05 /restore | 恢复词、网络、可选生日高度 | 校验 checksum；创建新密码 | 不上传恢复词；生日只是优化，不限制全扫描 |
| W06 /unlock | 钱包本地名称、密码 | 解锁会话 | 错误限流；无指纹、面容、验证码 |
| W07 /restore/progress | 可信高度、已扫高度、数据量 | 暂停/继续、检查点验证 | 未验证资产不显示为可花费 |
| W08 /security/password | 旧密码、新密码、重复 | 原子重包裹 DEK | 中断不能使旧新密码都无法打开 |
| W09 /security/export | 恢复词/加密备份两种明确选择 | 重新输本地密码 | 不默认分享给云盘或客服 |
| W10 /security/delete | 本地删除影响说明 | 二次确认并验证已知备份 | 不声称清除云端所有历史或销毁链上币 |

## 8.3 收付款页面

| ID/路由 | 内容与字段 | 主操作与校验 | 状态与验收 |
|---|---|---|---|
| W11 /wallet | 可用、质押、解锁、待确认、链同步 | 收款/转账/质押；余额眼睛图标 | 过期状态显示“截至高度…”而非实时 |
| W12 /receive | 新地址二维码、可选金额/订单/有效期 | 保存/分享收款请求；新建地址 | 收款不索取发送权限；地址已绑定本链 |
| W13 /scan | 摄像头取景、手动粘贴 | 解析 URI | 拒绝错链、脚本、过长或多义参数 |
| W14 /send | 地址/联系人、金额、加密备注 | 本地计划、余额与费检查 | 金额小数最多 8 位；不使用浮点 |
| W15 /send/confirm | 收款信息、金额、费、总扣款、隐私提示 | 点击确认；大额重新输本地密码 | 修改任一字段必须重新计划确认 |
| W16 /send/progress | 生成证明/签名/广播/验证状态 | 允许取消尚未广播工作 | 不能把广播成功显示为已到账 |
| W17 /transaction/:id | 金额、方向、费、时间、高度、状态 | 重播同一交易、导出选择性凭证 | 未知状态不允许“一键再付一笔” |
| W18 /history | 本地转入转出、质押、退出、费用过滤 | 查详情、加密导出 | 未恢复备注显示缺失，不自行编造 |
| W19 /invoices | 本地收款请求与匹配收款 | 已付/少付/多付/过期/重复 | 付款金额隐藏于公开链，商家本地可知 |
| W20 /invoice/:id | 请求内容、匹配记录、退款状态 | 新建退款交易 | 退款地址另行核对，无自动撤销 |
| W21 /contacts | 本地别名、地址、上次使用 | 新增/编辑/删除 | 不请求系统通讯录权限 |
| W22 /contacts/edit | 别名、链地址、本地备注 | 校验错链和名称冲突 | 不以同名昵称判定同一收款人 |

## 8.4 质押与验证者页面

| ID/路由 | 内容与字段 | 主操作与校验 | 状态与验收 |
|---|---|---|---|
| W23 /stake | 质押价值、净奖励、退出中、风险 | 开始质押、查看持仓 | 没有“每日领取赚收益”的诱导按钮 |
| W24 /validators | 状态、佣金、实际权重、签名率 | 过滤、排序、自主选择 | 不把项目自营节点静默设为唯一默认 |
| W25 /validators/:id | 公钥、佣金变更、历史处罚、集中度 | 委托、查看公开节点资料 | 外链仅经确认打开，不加载跟踪图片 |
| W26 /stake/new | 验证者、金额、预留费、公开信息说明 | 生成 position、min_shares | 默认不质押全部费余额 |
| W27 /stake/confirm | 本金、费、激活、14天双条件、罚没 | 本地确认并签名 | 风险确认不等于接受未知签名 |
| W28 /positions | 独立持仓列表、pending/active/refundable | 查看、退款、解除 | 不显示“可交易质押币” |
| W29 /positions/:id | 当前份额价值、公开关联范围、sequence | 部分/全部退出 | 最新状态验证失败不得签过时计划 |
| W30 /unbond | 份额/全部、预计金额、手续费来源 | 支持退出价值付费 | 全部余额已锁定场景必须通过 |
| W31 /unbond/confirm | 停奖规则、预计到期、风险、净额 | 确认真实退出动作 | 时间与高度两者都显示；链停则到期延后 |
| W32 /exit-tickets | 等待/处罚结算/可取回 | 合并选择有限数量领取 | “可取回”不提前加进可用余额 |
| W33 /exit-tickets/:id | 当前可取价值、扣罚事件、双截止 | ClaimExit | 重复领取明确拒绝且不二次扣费 |
| W34 /commission | 自营验证者佣金余额、历史领取 | ClaimCommission | 仅 operator 授权，不碰委托者余额 |
| W35 /node-request | 节点公钥、指纹、链、动作、有效期 | 批准注册/修改/轮换，回传签名 | 高风险再次输本地密码；无任意 sign bytes |

## 8.5 设置、隐私与故障页面

| ID/路由 | 内容与字段 | 主操作与校验 | 状态与验收 |
|---|---|---|---|
| W36 /settings | 安全、隐私、网络、语言、主题、版本 | 本地修改 | 不新增账户注册入口 |
| W37 /privacy | Tor 状态、公开边界、日志说明 | 重连、查看匿名性边界 | 没有静默直连开关；不保证绝对匿名 |
| W38 /network | 节点来源、可信高度、证人、延迟 | 切换合格独立端点 | 不能仅凭 HTTPS 就标链状态可信 |
| W39 /checkpoint | 信任过期原因、检查点签名与哈希 | 核对后导入可信检查点 | 禁止自动“信任所有 RPC” |
| W40 /diagnostics | 同步、缓存、存储、脱敏报告预览 | 用户主动导出 | 预览无种子/私钥/查看密钥/完整个人流水 |
| W41 /about | 版本、源码摘要、许可、协议版本 | 检查官方发布信息 | 无第三方广告分析或收益宣传 |

## 8.6 桌面节点管理页面

| ID/路由 | 字段与操作 | 验收重点 |
|---|---|---|
| N01 /welcome | 安装、导入既有节点路径、角色说明 | 明确运行节点不自动获得奖励 |
| N02 /preflight | CPU、RAM、SSD、剩余磁盘、网络、时钟 | 显示实测不足，不能永远绿色 |
| N03 /runtime | Linux/macOS 本机服务，Windows WSL2 状态 | 权限请求有解释；错误有恢复方法 |
| N04 /storage | 数据位置、预估占用、快照选择 | 不自动覆盖已有签名目录 |
| N05 /sync | 区块/状态/检查点进度与根验证 | 错快照不得启动签名 |
| N06 /keys | 共识公钥、签名状态、单写者保护 | 无“导入资金助记词”按钮 |
| N07 /register | 手机授权 QR、节点指纹与请求到期 | 离线核对，全请求已签名绑定 |
| N08 /dashboard | 候选/活跃/暂停、实际权重、错签警报 | 候选不伪装成活跃挖矿 |
| N09 /performance | CPU、内存、磁盘、网络、验证耗时 | 指标来自本机，无资金敏感标签 |
| N10 /peers | 已连 peer、独立哨兵、连接异常 | 公网 RPC 默认关闭 |
| N11 /staking | 自质押与公开委托池、佣金 | 资金操作必须手机或离线 operator 签名 |
| N12 /alerts | 漏签窗口、空间不足、时钟偏移、证据 | 能触发本机安全停签，不任意冻结链 |
| N13 /logs | 脱敏日志、筛选和导出 | 默认不含密钥或签名字节秘密 |
| N14 /updates | 软件签名、兼容性、升级高度与迁移 | 用户批准，不能后台静默替换共识 |
| N15 /migration | 停旧机、验证 signer 状态、轮换/迁移 | 同密钥双机测试不得被标“安全迁移” |
| N16 /uninstall | 停止服务、备份说明、保留或删除数据 | 不自动清除尚需恢复的密钥与状态 |

## 8.7 只读浏览器页面

E01 网络总览；E02 区块列表；E03 区块详情；E04 交易公开详情；E05 验证者列表；E06 验证者详情/佣金/证据；E07 总供给/发行/罚没与费用；E08 协议版本/公开升级信息。

| ID/路由 | 字段与动作 | 必须处理的状态 |
|---|---|---|
| E01 / | 最新验证高度、公开总供给、活跃权重、服务同步高度 | 索引落后明确标注；无个人余额 |
| E02 /blocks | 高度、时间、交易数、出块者，游标翻页 | 空链、分页到头、服务不可用 |
| E03 /blocks/:height | 头哈希、验证集合、公开交易ID、compact摘要 | 不存在与尚未索引区分 |
| E04 /inspect/:kind/:id | tx/position/ticket三类公开详情 | 错误ID、未知交易、proof待验证；不显示私密金额 |
| E05 /validators | 状态、权重、自质押、佣金、筛选排序 | 非活跃不写成正在出块 |
| E06 /validators/:id | 当前与历史共识键、公开事件、处罚/佣金时间线 | 证据加载失败不写成无处罚 |
| E07 /supply | T/Q/P/D/X/C/F/G、发行/罚没历史 | 不同高度不得混合计算；不以图表代替守恒 |
| E08 /protocol | 版本、参数摘要、发布签名、升级公告 | 公告未验证、不兼容、未达到升级高度 |

公开交易页只展示公开信息、证明类型与校验状态，不展示伪造的付款人地址或金额。搜索支持高度、tx_id、validator_id、position_id，**不提供以私密收款地址查个人全部流水**。任意页面不索取恢复词、私钥、查看密钥，不提供钱包登录。

## 8.8 关键错误文案

| 错误码 | 用户文案 | 允许动作 |
|---|---|---|
| E_NETWORK_UNKNOWN | 尚未确认交易结果，请勿重复付款 | 查询原交易、重播原交易 |
| E_PRIVACY_UNAVAILABLE | 隐私连接不可用，尚未直接连接交易服务 | 重连、稍后手动重试 |
| E_TRUST_EXPIRED | 可信检查点已过期，需要核对新的检查点 | 打开 W39 |
| E_STALE_QUOTE | 链状态已变化，需要重新核对金额和费用 | 重新计划，重新确认 |
| E_EXIT_IMMATURE | 尚未同时满足区块与时间解锁条件 | 查看两个条件 |
| E_SLASH_PENDING | 验证者处罚正在链上结算，资产操作暂不可执行 | 查看公开证据和进度 |
| E_INSUFFICIENT_FEE | 可用资金或本次释放价值不足支付费用 | 选择合法费用来源或补入本币 |
| E_SIGNER_ROLLBACK | 节点签名状态疑似回退，已停止签名 | 进入 N15，不自动重置 |

容量和末位验证者边界：W26/W27显示当前可接受的激活周期；配额不足不先扣款。N11和W30在操作会清空合格验证集合时解释最低自质押保留条件，不能显示“退出成功”。此条件不是普通委托用户的管理员锁定。

# 整数会计参考模型

运行：`python -m unittest discover -s reference -p 'test_*.py' -v`（项目根目录）。仅依赖 Python 标准库。

本模型针对**一个验证者池**和公共容器总额，验证整数份额、费用从退出值扣取、奖励、佣金、技术供给上限、退出双条件、处罚与重复领取。它不是链源码，不包含密码学、共识、多池分配、并行处罚任务、真实网络、磁盘恢复或钱包。测试成功不表示那些模块完成。

模型中的 maturity 时间由测试者显式传入，不能把它当作运行链可读取本地墙钟的许可。实际链必须使用已验证的区块时间、真实验证集合与队列。随机测试固定种子只为可复现，不用于生成任何钱包秘密。

在 Rust 实现中将此 oracle 与链执行器做差分测试，并另增完整属性测试；不要把 Python 模型作为生产资金后台。

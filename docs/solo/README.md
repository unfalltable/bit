将本目录放入新项目仓库根目录，在该目录打开 Codex，使用 `codex/START_PROMPT.md` 的全文作为启动指令。保留根目录 `AGENTS.md`，不要只传一个页面表就让模型自由猜测底层协议。[S21]

## 本包已确定的设计

Rust自定义状态机与CometBFT0.38，通过ABCI2.0集成；仅复用选定上游Spend/Output原语；普通支付隐私，质押采用公开独立公钥原生持仓；不可转让的内部份额不是第二个可流通币；Flutter+Rust钱包；本地密码/加密备份；Tor默认且不静默直连；全量本地扫描并验证；完整质押、收益、退出、处罚、恢复及节点密钥迁移。

这不是“全部行为绝对匿名”：质押金额、position及其生命周期、验证者与网络元数据有明确公开/可关联边界。没有任何材料保证资金永远不会被盗。正式软件的安全结论必须来自实际实现与独立审查。

## 现在可以运行的检查

```bash
python -m pip install -r requirements-validation.txt
python tests/validate_bundle.py
python -m unittest discover -s reference -p 'test_*.py' -v
```

这些命令只检查本规格包和数学模型。其余 `just localnet`、钱包构建等命令是Codex需要实现的正式软件交付内容，当前包不伪造它们已经存在。不要把这里的Python模型部署为中心化资产后台。

## 主网不允许虚构的输入

真实创世分配与公钥签署、真正独立的验证者/查询资源、生产参数内容哈希、安全审查报告、发布/商店签名凭证、适用服务地区确认。模板中的空值和mainnet_ready=false是有意保留；开发可按完整testnet参数直接进行，但主网放行必须有真实证据，不得通过改布尔值或填样例密钥绕过。

技术版本是2026-09-07核验的参考基线；不是整套依赖已编译兼容的声明。D-001负责实测并冻结源码提交、锁文件、平台矩阵与ZK参数manifest。变更必须写ADR、同步合同并重新测试。
